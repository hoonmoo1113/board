# 결과 예측판 (드래프트식) — Express + Turso + Render

표(칸)를 직접 만들고, 참가자들이 순서를 돌아가며 빈칸을 골라 자기 색·이름으로 채우는 앱입니다.

- 표 구성(제목·구분 열·예측 열·행 목록)을 진행자가 직접 입력 → 칸 수/글자 자유
- 참가자는 이름을 넣고 참여, 내 차례에 빈칸을 눌러 채움 → 색깔로 구분
- 순서: 참가자 순서대로 돌아가며, "한 번에 고르는 칸 수"를 1~N으로 바꿀 수 있음(예: A가 2~3개 먼저)
- 진행자는 시작/다음 차례/현재 차례 지정/대리 입력/칸 지우기/초기화 가능

## 배포 (다른 앱과 동일)
1. Turso: DB 생성 → URL·토큰 (또는 기존 DB 재사용)
2. GitHub: 새 저장소에 이 폴더 업로드 (.env 제외)
3. Render: Web Service → Runtime Node, Build `npm install`, Start `npm start`
   - 환경변수: TURSO_DATABASE_URL, TURSO_AUTH_TOKEN, ADMIN_PIN
4. 배포 주소 → 하단 "진행자 화면" → PIN(기본 1234) → 표 만들기 · QR 배포

## 사용 순서
1. 진행자: "표 만들기"에서 제목/열/행 입력 후 저장 → 참가자 관리(직접 추가 또는 QR로 참여)
2. 순서 정하고 "시작" → 참가자가 자기 차례에 빈칸 탭(진행자 화면에서 대리 입력도 가능)
3. "한 번에 고르는 칸 수"를 바꾸면 A가 여러 칸 연속 선택 후 다음 차례로 넘어감
4. 다 채우면 완료. "칸만 초기화"로 다시 시작 가능.

행 입력 예시:
```
KO/TKO | 1라운드
KO/TKO | 2라운드
서브미션 | 1라운드
| 판정 만장일치
```
